# Your Choice Family Restaurant

GitHub-ready frontend starter for the Haldia restaurant.

## Included
- Responsive customer website
- Menu and search
- Cart
- Cash on Delivery checkout UI
- Table booking UI (up to 10 guests)
- Google Maps button
- Gallery placeholders for original restaurant photos
- Clean separation for later Cloudflare Worker + D1 backend

## Important
This ZIP is a frontend starter. Orders and bookings currently log to the browser console; they are NOT yet stored in a database and the admin panel/authentication is not production-ready.

## Deploy
Upload the files to GitHub with `index.html` in the repository root. Then connect the repository to Cloudflare Pages/Workers as the next step.

## Add photos
Put the restaurant images inside `assets/`, then replace the gallery placeholders in `index.html` with `<img src="assets/your-file.jpg">`.
